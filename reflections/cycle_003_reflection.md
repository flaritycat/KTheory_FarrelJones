## Cycle summary

### BNS and normal-subgroup route boundary

`FJ41`--`FJ43` completed the bounded BNS/Bieri/Karrass--Solitar decision
window selected by the cycle-002 reflection and the strategic audit.

The cycle verified the original Bieri--Neumann--Strebel finite-generation
theorem map for normal subgroups with abelian quotient, but it did not
compute a new \(\Sigma(G)\)-membership condition and did not produce a
finite-rank free-kernel bridge.

`FJ42` kept Bieri (1976) out of theorem-use status because the primary
theorem text was not directly checked. `FJ43` then correctly paused automatic
continuation of the source cluster.

**Warning.** Direct BNS theorem use is now available only as a theorem map.
It is not a candidate generator unless a future module supplies an invariant
computation or another bridge.

### Finite-index and source-convention control

`FJ44`--`FJ50` tested `RB-005`, the finite-index and virtually compact
special formulation bucket.

The most important positive governance result was the `FJ02` interruption.
The project now has a first-pass additive-category source convention, and
`FJ47` records the `FJCw` finite-index overgroup bridge as `ER-014`.

The route result for `T-001` was still negative:

- the full \(\mathcal{FJ}\) finite-index bridge remains formulation-specific;
- the `FJCw` bridge has no current `T-001` application case;
- the direct CAT(0) finite-extension lane is not licensed by the checked
  source status.

**Remark.** This was not wasted work. It prevents future finite-index claims
from silently collapsing full Farrell--Jones, coefficient K-theory FJC,
`FJCw`, `FICwF`, and CAT(0)-route statements.

### RB-006 demotion

`FJ51`--`FJ54` tested the Louder--Wilton / negative-immersion boundary for
`RB-006`.

The outcome is conservative:

- Louder--Wilton supplies useful negative-immersion and \(\pi(w)>2\) boundary
  information;
- the current source chain routes only through hyperbolicity and hence
  through `FJ23`;
- `FJ53` remains WIP / provisional;
- `RB-006` is demoted as provisionally non-subtractive unless a genuinely
  non-hyperbolic CAT(0), compact-special, or Farrell--Jones bridge appears.

**Warning.** The project should not count the \(\pi(w)>2\) path as a new
residual subtraction unless a specific word is checked and the route is
recorded through the hyperbolic ledger.

### Hybrid attack packet and candidate-production obstruction

`FJ54` selected the `RB-003` + `RB-004`/`RB-008` hybrid packet:
hierarchy / primitive-extension data combined with explicit kernel-control
testing.

`FJ55`--`FJ57` then forced the hard question. The result was not a proof
attempt but a documented obstruction:

- hierarchy data alone is not a Farrell--Jones route;
- all concrete kernel-control rows in the candidate inventory are
  calibration-only or already removed through `FJ26`;
- the template row is not a mathematical candidate;
- no repository-supported non-routed candidate can be promoted without
  fabrication.

This is the central cycle-003 diagnosis: `T-001` is still mathematically
important, but the repository currently lacks a live candidate-production
lane.

### Weaker consequence lane

`FJ58`--`FJ60` tested the lower-priority weaker \(K_0\) / Cohen--Lyndon
consequence lane.

The lane did not produce a payload. The existing \(K_0\)-level consequences
remain conditional on Farrell--Jones, and no exact Cohen--Lyndon-style source
payload is recorded.

`FJ60` closes this lane as inactive by recording `OBL-T001-007`.

**Warning.** `OQ-024` remains open. The project has not recorded a weaker
global K-theoretic theorem for all torsion-free one-relator groups.

## What worked

Cycle 003 did not drift into decorative bibliography. It repeatedly forced
route-delta decisions:

- `RB-004` source continuation was paused when it produced no candidate;
- `RB-005` was paused after finite-index and formulation tests had no
  application case;
- `RB-006` was demoted when the route overlapped hyperbolicity;
- the hybrid packet was blocked rather than padded with invented examples;
- the weaker consequence lane was closed rather than allowed to become a
  classical-source survey.

The candidate inventory is now the strongest governance artifact. It makes
clear which rows are exhausted and what a future candidate must supply.

## What remains fragile

1. `T-001` has no live non-routed candidate row.
2. `FJ53` is still WIP / provisional and must not be silently finalized.
3. `RB-004`, `RB-005`, `RB-006`, and `RB-008` remain mathematically relevant
   but dormant without new candidate data.
4. `OQ-024` remains open, but the weaker consequence lane is inactive until
   an exact source payload is named.
5. The project risks turning "find a candidate" into another source-reading
   prompt unless the next module sets strict intake and exit criteria.

## Cycle 004 posture

Cycle 004 should not begin with another external source. It should begin by
deciding whether `T-001` can still be run as an active proof-target cycle or
whether it should be paused pending new candidate data.

The correct next move is:

```text
FJ61. T-001 Candidate-Intake Reset and Exit Criteria
```

`FJ61` should be an internal governance and attack-packet module. It should
not verify a new theorem source. It should consolidate the active
obligations, define what counts as a legitimate new candidate, and decide the
first cycle-004 branch.

## Decision

**Reflection decision.** Cycle 003 is closed. `T-001` remains an important
recorded target, but it is not currently candidate-ready. The next
mathematical move is `FJ61`, a candidate-intake reset and exit-criteria
module.

`FJ61` must produce one of:

- a legitimate candidate-intake branch;
- a concrete bridge or computation requirement;
- a target-pause recommendation;
- a target-pivot comparison.

It must not produce a source summary.
