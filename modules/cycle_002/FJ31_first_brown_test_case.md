## Definitions

**Definition.** The first Brown test case is
\[
G=\langle x,y\mid xyx^{-1}y^{-1}\rangle
\]
with the epimorphism \(\chi\colon G\to\mathbb Z\) defined by
\(\chi(x)=1\) and \(\chi(y)=0\).

**Definition.** For a cyclically reduced relator
\[
r=x_1x_2\cdots x_n,
\]
the Brown initial-segment sequence for \(\chi\) is the sequence
\[
\chi(s_i),\qquad s_i=x_1x_2\cdots x_{i-1},\quad 1\leq i\leq n.
\]

**Warning.** This is a calibration example. Since
\(G\cong\mathbb Z^2\), it is already removed by the virtually solvable route
from `FJ25`. It is also a finite-rank free-by-cyclic group. The module does
not identify a new unsolved Farrell--Jones case.

## Main work

### Presentation and map

Let
\[
G=\langle x,y\mid r\rangle,\qquad r=xyx^{-1}y^{-1}.
\]

Define
\[
\chi(x)=1,\qquad \chi(y)=0.
\]

This is an epimorphism \(G\to\mathbb Z\).

### Brown test for \([\chi]\)

The relator letters are
\[
x,\ y,\ x^{-1},\ y^{-1}.
\]

The proper initial segments are:

| \(i\) | \(s_i\) | \(\chi(s_i)\) |
|---|---|---|
| 1 | \(1\) | 0 |
| 2 | \(x\) | 1 |
| 3 | \(xy\) | 1 |
| 4 | \(xyx^{-1}\) | 0 |

The maximum is \(1\), and it occurs exactly twice.

Because \(\chi(y)=0\), this is the zero-on-one-generator case in Brown's
Theorem 4.3 as recorded in `FJ30`. The relevant maximum-count condition is
that the maximum occur exactly twice. Therefore \([\chi]\) passes Brown's
criterion.

### Brown test for \([-\chi]\)

For \(-\chi\), the initial-segment values are:

| \(i\) | \(s_i\) | \(-\chi(s_i)\) |
|---|---|---|
| 1 | \(1\) | 0 |
| 2 | \(x\) | -1 |
| 3 | \(xy\) | -1 |
| 4 | \(xyx^{-1}\) | 0 |

The maximum is \(0\), and it occurs exactly twice.

Again Brown's zero-on-one-generator condition applies, so \([-\chi]\) passes
Brown's criterion.

### Kernel and route bridge

Brown's Corollary 3.2, as recorded in `FJ30`, implies that
\(\ker(\chi)\) is finitely generated because both \([\chi]\) and
\([-\chi]\) pass the criterion.

In this particular example the kernel can be identified directly:
the relator is the commutator \([x,y]\), so
\[
G\cong\mathbb Z^2
\]
with \(x\) and \(y\) commuting. The map \(\chi\) is projection onto the
\(x\)-coordinate, and
\[
\ker(\chi)=\langle y\rangle\cong\mathbb Z=F_1.
\]

Therefore
\[
1\to F_1\to G\to\mathbb Z\to 1
\]
is a finite-rank free-kernel exact sequence. It splits by sending
\(1\in\mathbb Z\) to \(x\in G\), hence
\[
G\cong F_1\rtimes\mathbb Z.
\]

This supplies the finite-rank free-by-cyclic bridge required by `FJ26`.

### Route overlap

This example should not be counted as a new residual removal. It is already
covered by the virtually solvable route from `FJ25`, and the Brown test only
calibrates the `RB-004` workflow.

## Proposition / Theorem / Conjecture / Example

**Example.** For
\[
G=\langle x,y\mid xyx^{-1}y^{-1}\rangle
\]
and \(\chi(x)=1,\chi(y)=0\), Brown's two-generator one-relator criterion
verifies both \([\chi]\) and \([-\chi]\). Consequently
\(\ker(\chi)\cong F_1\), and \(G\cong F_1\rtimes\mathbb Z\).

**Proof.** The Brown initial-segment values for \(\chi\) are
\[
0,\ 1,\ 1,\ 0,
\]
so the maximum occurs exactly twice. The values for \(-\chi\) are
\[
0,\ -1,\ -1,\ 0,
\]
so the maximum again occurs exactly twice. Since \(\chi(y)=0\), Brown's
zero-on-one-generator case applies in both directions. Brown's Corollary 3.2
then gives finite generation of \(\ker(\chi)\).

The presentation is the standard presentation of \(\mathbb Z^2\), so the
kernel of projection onto the \(x\)-coordinate is generated by \(y\). Thus
\(\ker(\chi)\cong\mathbb Z=F_1\), and the sequence splits by the generator
\(x\).

**Warning.** This example is already Farrell--Jones-positive inside the
project through earlier known routes. The point of the module is the Brown
criterion workflow, not a new known-case result.
