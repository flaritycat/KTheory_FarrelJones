## Definitions

**Definition.** A candidate-production lane is a continuation path that can
produce, in the next bounded module, at least one of:

- a named group or family with a presentation;
- a bridge lemma with checkable hypotheses;
- a concrete computation attached to a residual row;
- a prior-art blocker that changes the project status of a candidate.

**Definition.** A dormant residual lane is an unresolved bucket that remains
mathematically important but is not currently candidate-ready inside the
repository.

**Definition.** A consequence-lane intake is a bounded module that asks
whether a weaker consequence, such as a \(K_0\)-level or Cohen--Lyndon-style
statement, can update an open question, proof obligation, or prior-art
blocker without being counted as a Farrell--Jones residual subtraction.

**Warning.** A consequence-lane intake is not a proof of `T-001`, not a
global Farrell--Jones theorem for torsion-free one-relator groups, and not a
substitute for a residual-bucket subtraction.

### Checkpoint decision

**Route decision.** No current residual-bucket lane is candidate-ready enough
to replace the blocked `RB-003` + `RB-004`/`RB-008` hybrid packet as a proof
attempt.

This is a project-state obstruction, not a theorem that no candidate exists.
It says only that the repository cannot presently continue `T-001` proof work
without importing a new candidate, theorem payload, computation, or prior-art
comparison.

**Obstruction OBL-T001-005.** After the `FJ58` post-hybrid checkpoint, the
project has no active candidate-production lane for `T-001`.

To reopen candidate-level proof work, a later module must supply at least one
of:

- a named torsion-free one-relator presentation or family not already routed;
- a bridge lemma with exact hypotheses and a route-output target;
- a concrete BNS/Brown/kernel computation outside the exhausted rows;
- a formulation-safe finite-index or `FJCw` application case;
- a non-hyperbolic compact-special/CAT(0)/FJ bridge for `RB-006`;
- a prior-art comparison that changes the status of a current candidate.

### Selected next bounded module

Since no candidate-production lane is currently ready, the next module should
not claim to continue a proof attempt. The least dishonest continuation is a
bounded lower-priority intake:

`FJ59`: Weaker \(K_0\) / Cohen--Lyndon Consequence Intake Gate.

`FJ59` should address `OQ-024` only as an intake question. Its job is to
decide whether a weaker \(K_0\)-level or Cohen--Lyndon-style source payload
can change a proof obligation, prior-art blocker, or consequence ledger. It
must not be recorded as a Farrell--Jones route subtraction unless it supplies
the full required formulation and route data.

### Stop conditions for FJ59

- Stop if the source payload is only motivational background.
- Stop if the statement is \(K_0\)-level but cannot be connected to a
  project open question or consequence ledger.
- Stop if the statement is a Cohen--Lyndon theorem with no Farrell--Jones,
  \(K_0\), finiteness-obstruction, or candidate-production consequence.
- Stop if the formulation is weaker than full `T-001` and the module cannot
  state exactly what remains unproved.
- Stop if the result is already absorbed by `FJ08`, `FJ09`, `FJ23`--`FJ27`,
  or an existing candidate row.
