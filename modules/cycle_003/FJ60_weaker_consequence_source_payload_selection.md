## Definitions

**Definition.** A weaker consequence source payload is an exact source-backed
theorem package consisting of a citation, theorem statement, hypotheses,
formulation level, and project object changed. The formulation level must be
one of: full Farrell--Jones, coefficient K-theory FJC, `FJCw`, simplified
ring-coefficient Farrell--Jones, \(K_0\)-level only, finiteness-obstruction
only, or purely group-theoretic.

**Definition.** An inactive consequence lane is a project lane that remains
mathematically relevant but is not active as a module sequence. It can be
reopened only by naming a payload that changes a candidate row, residual
bucket, open question, proof obligation, consequence ledger, or prior-art
blocker.

**Warning.** Classical one-relator sources recorded as `found; to verify` are
not payloads until a later module verifies an exact theorem and records its
project effect.
