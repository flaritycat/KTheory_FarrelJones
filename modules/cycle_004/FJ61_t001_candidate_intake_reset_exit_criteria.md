## Definitions

**Definition.** A candidate-admissible row is a `T-001` candidate row with
enough recorded data to drive a bounded proof, bridge, computation, or
documented obstruction module. It must not be a template placeholder,
calibration example, already routed row, or source name without a candidate.

**Definition.** The candidate-intake gate is the checklist that a proposed
`T-001` candidate, bridge, computation, or source payload must pass before it
can become the subject of a proof-target module.

**Definition.** An exit decision is a cycle-level decision to continue
`T-001`, pause it pending data, redirect to a bridge or computation, or
compare target pivots.

**Warning.** A candidate-intake reset is not a mathematical theorem and is
not evidence that `T-001` is false or solved. It is a governance checkpoint
against unsupported proof attempts.

### Candidate-admissible row checklist

Before any future module treats a `T-001` row as active, the row must record
all fields below.

| Field | Required content | Stop condition |
|---|---|---|
| Candidate identity | named group or family with presentation | stop if only a source topic, bucket label, or placeholder is present |
| Target status | relator proper-power status and torsion-free status, or explicit unknown labels | stop if the row cannot be checked as relevant to `T-001` |
| Residual status | explanation of why the row is not already removed by `FJ23`--`FJ27` or marked calibration-only | stop if it is already hyperbolic, finite-dimensional CAT(0), virtually solvable, finite-rank free-by-cyclic, inherited, or only illustrative |
| Route-output target | one intended output: hyperbolicity, finite-dimensional CAT(0)/special input, finite-rank free or hyperbolic kernel extension, version-safe inheritance, exact weaker payload, or documented obstruction | stop if no route output is named |
| Required data | bridge lemma, concrete computation, source theorem payload, prior-art comparison, or obstruction to be checked | stop if the next action is only "read more" |
| Formulation safety | full \(\mathcal{FJ}\), coefficient K-theory FJC, `FJCw`, simplified ring-coefficient, \(K_0\)-level, or group-theoretic status | stop if source labels are collapsed |
| Prior-art risk | known / blocked / unknown, with a comparison task when unknown | stop novelty language if comparison is absent |
| Exit condition | continue, route, demote, pause, or pivot condition | stop if success and failure conditions are not stated |

### Allowed route-output targets

Future `T-001` modules may proceed only if they name one of the following
outputs.

| Output target | Required input | Non-use warning |
|---|---|---|
| Hyperbolicity route | source-verified or internally proved bridge to word-hyperbolicity | count through `FJ23`, not as a new residual route |
| Finite-dimensional CAT(0) / special route | source-verified bridge to the finite-dimensional CAT(0) route or a formulation-safe special-cube route | do not use virtual specialness without finite-index formulation control |
| Finite-rank free or hyperbolic kernel extension | explicit epimorphism, kernel type, quotient, and matching extension theorem | an epimorphism to \(\mathbb Z\) alone is insufficient |
| Version-safe inheritance | exact inheritance theorem, hypotheses, source label, and subgroup or quotient data | do not merge full \(\mathcal{FJ}\), coefficient FJC, `FJCw`, and `FICwF` |
| Exact weaker payload | theorem statement, hypotheses, formulation level, source status, and project object changed | not a residual subtraction unless it supplies a full FJ route |
| Documented obstruction | checked reason a candidate or lane cannot proceed | not a mathematical nonexistence theorem |
